# DeskMew Privacy Policy / DeskMew 隐私政策

**Effective date / 生效日期: November 24, 2026 / 2026 年 11 月 24 日**

## 中文

DeskMew（以下简称"本应用"）是一款 Windows 桌面宠物应用：一只趴在键盘上的猫，会跟随你的打字与鼠标动作做出反应。本隐私政策说明本应用如何处理相关数据。

### 1. 输入数据的处理

为实现键盘互动，本应用在运行期间通过 Windows Raw Input API 访问键盘事件，仅识别"哪个物理按键被按下"，以便让猫用对应的爪子敲击键盘。按键的文本内容不会被读取、记录或存储，本应用不包含键盘记录功能。

为实现鼠标跟随与互动，本应用会读取鼠标指针的屏幕坐标，使猫的头部和瞳孔跟随光标转动，并响应鼠标点击（例如摸头、拖动窗口）。上述输入数据仅在用户设备上实时处理，不会被写入文件，也不会发送到开发者或任何第三方服务器。

本应用不会读取或记录剪贴板内容、活动窗口标题、正在运行的进程名称或屏幕内容。

### 2. 应用设置

本应用会在用户设备本地保存应用设置，包括皮肤选择、窗口主题、窗口位置和开机启动状态，保存位置为：

`%LOCALAPPDATA%\BlackCatPet\settings.json`

### 3. 网络传输、共享与出售

本应用不包含用户账户、广告、在线分析或遥测功能，运行期间不发起任何网络请求。本应用不会上传、共享或出售个人数据，也不会将输入数据用于广告、用户画像或跨应用跟踪。

Microsoft Store 可能根据其自身隐私政策处理应用下载、购买、许可、崩溃报告或商店使用数据；该处理由 Microsoft 控制，不属于本应用的数据处理行为。

### 4. 数据控制与删除

用户可以随时删除上述设置文件（`%LOCALAPPDATA%\BlackCatPet\settings.json`）来清除本应用保存的全部本地数据。卸载本应用后，用户也可以检查并手动删除该目录中可能保留的文件。

### 5. 儿童隐私

本应用不面向儿童收集个人数据，也不会有意将任何数据上传给开发者或第三方。

### 6. 政策变更

如果本应用的数据处理方式发生重大变化，本隐私政策将同步更新，并修改页面顶部的生效日期。

### 7. 联系方式

如对本隐私政策有疑问，请通过电子邮件 jackyshen2002@hotmail.com 联系开发者。

## English

DeskMew (the "App") is a Windows desktop pet application: a cat that rests on your keyboard and reacts to your typing and mouse activity. This Privacy Policy explains how the App handles related data.

### 1. Processing of input data

To provide keyboard interaction, the App accesses keyboard events through the Windows Raw Input API while it is running. It only recognizes WHICH physical key was pressed, so the cat can tap the keyboard with the corresponding paw. The textual content of keystrokes is not read, recorded, or stored, and the App contains no key-logging functionality.

To provide mouse following and interaction, the App reads the screen coordinates of the mouse pointer so the cat's head and pupils turn toward the cursor, and it responds to mouse clicks (for example, petting the cat or dragging the window). This input data is processed locally on the user's device in real time; it is not written to any file and is not transmitted to the developer or to any third-party server.

The App does not read or record clipboard contents, active window titles, running process names, or screen contents.

### 2. App settings

The App stores application settings locally on the user's device, including the selected skin, window theme, window position, and auto-start preference. Settings are stored at:

`%LOCALAPPDATA%\BlackCatPet\settings.json`

### 3. Network transmission, sharing, and sale

The App does not provide user accounts, advertising, online analytics, or telemetry, and it does not make any network requests while running. The App does not upload, share, or sell personal data, and it does not use input data for advertising, profiling, or cross-app tracking.

Microsoft Store may process download, purchase, licensing, crash-reporting, or Store usage data under Microsoft's own privacy terms. Such processing is controlled by Microsoft and is separate from the App's data handling.

### 4. User control and deletion

Users may delete the settings file (`%LOCALAPPDATA%\BlackCatPet\settings.json`) at any time to remove all locally stored data. After uninstalling the App, users may also inspect and manually delete any files that remain in that directory.

### 5. Children's privacy

The App is not designed to collect personal data from children and does not knowingly upload any data to the developer or third parties.

### 6. Changes to this policy

If the App's data-handling practices change materially, this Privacy Policy will be updated and the effective date at the top of this page will be revised.
